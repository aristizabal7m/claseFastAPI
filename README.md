REQUERIMIENTOS FUNCIONALES
- El sistema debe poder permitir insertar un prompt
- El sistema deber poder procesar el prompt
- El sistema debe poder dar una repsuesta al prompt
- El sistema debe actualizar sus datos constantemente
- El sistema debe poder guardar el historial de prompts
REQUERIMIENTOS NO FUNCIONALES
- El sistema debe poder leer el prompt en menos de 1 segundo
- El sistema debe dar una respuesta al prompt en menos de 10 segundo
- El sistema debe cargar la informacion en menos de 1 segundo
- El sistema debe tener una disponibildad el 90% de las veces
- El sistema debe soportar muchos usuarios conectados al mismo tiempo
